# Course project figure

`probe-guided-vlm.png` is the screenshot supplied by Zhangyu Wang for the CSCI 444 course project, copied without image modifications.

Project: **Probe-Guided Optimization for Object Hallucination Mitigation in Large Vision-Language Models**.

Zhangyu Wang and Qinling Hou contributed equally, as specified by Zhangyu Wang. The uploaded report spells the second author's name Qinglin Hou; the webpage currently follows the user-supplied spelling.

The title and short project description come from `CSCI444_Final_Report.pdf`. The figure shows synthetic CLEVR-MATE data generation, linear probe training, and probe-guided intervention during inference.
